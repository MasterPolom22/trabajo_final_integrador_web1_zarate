# Impulso 3D-SL

## Descripción del proyecto

Este proyecto consiste en el desarrollo de un sitio web para Impulso 3D-SL, un emprendimiento dedicado a la impresión 3D personalizada.

El sitio permite conocer el emprendimiento, visualizar sus productos y servicios, contactarse mediante un formulario, la tienda esta en construccion por eso no existe todavia.

## Páginas del sitio

- **Inicio:** presenta el emprendimiento y cuenta con un carrusel de imágenes con navegación manual y automática.
- **Productos:** muestra los productos y servicios mediante una distribución de columnas.
- **Contacto:** incluye un formulario con validaciones realizadas mediante JavaScript y la visualización de un resumen cuando los datos son válidos.
- **Tienda:** esta sección se encuentra en construcción, por lo cual solo se ve un cartel(en construcción), si se llegara a seguir esta parte se convertiría en la tienda online donde podes seleccionar y comprar producctos.

## Tecnologías utilizadas

- HTML5 para la estructura del sitio.
- CSS3 para el diseño y la adaptación a distintos dispositivos.
- JavaScript para el carrusel y la validación del formulario.

## Estructura del proyecto

index.html: página de inicio.
productos.html: página de productos y servicios.
contacto.html: página de contacto.
tienda.html: página de tienda online(en cosntrucción).
css/estilos.css: estilos del sitio.
js/scrip.js: funcionamiento del carrusel.
js/formulario.js: validación del formulario.
js/productoDetalle.js:aca esta la logica al clickear detalles del producto la ventana modal 
img/: imágenes y recursos gráficos.
